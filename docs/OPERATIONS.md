# 管理员运维手册

本文档面向机器人管理员，说明日常使用、配置调整、抽奖管理、备份恢复和升级检查流程。

## 首次上线检查

上线前请确认：

1. 已在 `config.yaml` 中填写 `bot.token`
2. 已在 `config.yaml` 中填写至少一个 `bot.admin_ids`
3. 机器人已通过 `@BotFather` 关闭 `Privacy Mode`
4. 机器人已加入目标群
5. 若需要抽奖结果置顶，机器人已具备群管理员置顶权限
6. 若希望自动删除提示消息，机器人已具备删除消息权限
7. 若环境无法直接访问 Telegram，已正确配置代理

## 群组绑定

### 固定群模式

当 `config.yaml` 中已配置 `bot.group_id` 时：

- 启动后自动绑定该群
- 不支持运行时解绑
- 机器人只服务该群

### 动态绑定模式

当 `bot.group_id: null` 时：

1. 先将机器人加入目标群
2. 在目标群中由群管理员或 Bot Admin 执行 `/bind_group`
3. 成功后机器人开始服务该群

说明：

- 若当前已经绑定其他群，只有 Bot Admin 可以重新绑定
- 解绑命令为 `/unbind_group`

## 常用命令

### 普通用户

- `签到` 或 `/checkin`
- `积分` 或 `/points`
- `排行榜` 或 `/rank`
- `抽奖` 或 `/lotteries`
- `参与 <ID>`

### 群管理员

- `/lottery ...`
- `/draw <ID>`
- `/cancel_lottery <ID>`

### Bot Admin

- `/settings`
- `/add_points <用户ID> <积分>`
- `/sub_points <用户ID> <积分>`
- `/set_points <用户ID> <积分>`
- `/backup`
- `/restore`

## 私聊配置面板

### 入口

- 私聊机器人，发送 `/settings`

### 允许使用的人

- Bot Admin
- 当前已绑定群的管理员

### 可修改项目

- 签到积分
- 文字最少字数
- 文字积分
- 贴纸积分
- 图片积分
- 每日聊天积分上限
- 聊天积分冷却秒数
- 排行榜显示人数
- 抽奖默认最少人数

### 注意事项

- 修改写入数据库覆盖层，不会直接改 `config.yaml`
- 重启后仍然生效
- 如果需要恢复为 YAML 默认值，需要手动改回目标值，或清理数据库 `config` 表对应键

## 抽奖管理

### 创建抽奖

手动开奖：

```text
/抽奖 标题|奖品|积分|3
```

满人数自动开奖：

```text
/抽奖 标题|奖品|积分|人数:10
```

定时开奖：

```text
/抽奖 标题|奖品|积分|时间:2026-04-13 20:00|3
```

### 开奖

手动开奖命令：

```text
/开奖 <抽奖ID>
```

说明：

- 仅手动开奖模式支持该命令
- 满人数开奖和定时开奖会自动结算

### 取消抽奖

```text
/取消抽奖 <抽奖ID>
```

说明：

- 已参与用户会自动退款

### 结果置顶

- 抽奖结果会尝试在群内置顶
- 若失败，通常是机器人缺少置顶权限

## 备份与恢复

### 手动备份

```text
/backup
```

### 手动恢复

```text
/restore
```

### 建议流程

恢复前建议先做一次手动备份，避免误操作导致现场数据丢失。

## 升级检查单

升级前：

1. 备份 `data/points_bot.db`
2. 备份 `config.yaml`
3. 记录当前绑定群 ID
4. 若启用 `/settings`，确认当前关键覆盖值

升级后：

1. 观察启动日志是否有数据库初始化异常
2. 在目标群测试 `签到`
3. 在目标群测试 `积分`
4. 在目标群测试 `抽奖`
5. 在私聊测试 `/settings`
6. 检查 Telegram 命令菜单是否刷新

## 常见运维问题

### 菜单没有刷新

- 先等待几秒
- 重新打开聊天窗口
- 确认机器人已成功启动
- 确认绑定或解绑操作已执行成功

### 机器人能响应斜杠命令，但不响应文字命令

通常是 `Privacy Mode` 未关闭。

### 恢复后配置和预期不一致

优先检查数据库 `config` 表中的运行时覆盖值，因为它会覆盖 YAML 默认值。
